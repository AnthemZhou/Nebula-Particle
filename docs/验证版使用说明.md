# Nebula Particle 0.5.0 使用说明

日期：2026-11-12。本文描述 0.5.0 的功能范围，与 V1.0 产品验收目标分开。0.5.0 统一产品名称并提供用户级安装包，沿用 v0.2 的分组和预设工作流；渲染核心仍为二维 CPU 实现。

## 1. 安装与打开

下载并解压 `Nebula-Particle-0.5.0-macos-arm64.zip`，保存工程并退出 AE，然后运行包根目录的 `install-macos.command`。发布包安装不需要 SDK。完整步骤、ad-hoc 签名说明与旧版本兼容规则见[安装说明](安装说明.md)；只有自行构建时才需要 [Adobe SDK](SDK准备.md)。

启动新会话后在“效果和预设”中搜索 **Nebula Particle**；从“窗口”菜单打开 **Nebula Particle Presets.jsx**。

开发时也可从“文件 → 脚本 → 运行脚本文件”运行 `scripts/Nebula Particle Presets.jsx`。`NebulaParticlePresetLib.jsxinc` 必须与 JSX 同目录。直接运行时是浮动窗口；安装为 ScriptUI Panel 后由 AE 管理面板。

## 2. 原生效果面板

顶层只保留四个参数：

| 参数 | 含义 |
| --- | --- |
| Preset | 6 个内置起点；切换时重新应用其视觉值 |
| Density (births/sec) | 每秒出生数量 |
| Size (px) | 粒子基础大小 |
| Lifetime (sec) | 存活时间，同时影响拖尾持续长度 |

下列组默认折叠：

| 分组 | 主要控件 |
| --- | --- |
| Sources | Source、Emit from、Color map、External emission mask、Show source |
| Appearance | Particle shape、Particle blend、Color mode、Tint color、Glow、Opacity |
| Animation | Fade in、Fade out、Twinkle strength、Twinkle frequency |
| Advanced → Motion | Initial speed、Direction、Spread、Damping |
| Advanced → Timing | Random seed、Prewarm、Stop emission |
| Advanced → Development | Reload current preset |

默认折叠是新效果的初始状态。已经保存的工程可能保留用户自己的展开状态。

### 来源

- **Source** 不选择图层时，使用当前效果输入。
- **Emit from** 支持 Alpha、Luminance、External luminance、Full frame。
- **External emission mask** 在外部亮度模式下提供出生分布。
- **Color map** 不选择图层时使用发射来源；可以连接另一张颜色图。
- **Show source** 控制是否将源图像合成进输出，关闭后只输出透明粒子。

背景浮尘请配合 **Emit from → Full frame**。切换预设不应暗中改变已经连接的来源或外部亮度通道。

### 运动、动画与外观

- **Initial speed** 为出生初速，单位像素/秒；Direction 中 0° 向右、90° 向下。
- **Damping** 为每秒指数阻尼。0 时保留速度，数值越大减速越快；只在 Advanced → Motion 中出现。
- **Fade in / Fade out** 使用寿命百分比，与闪烁独立。
- **Twinkle strength / frequency** 控制存活期间的明暗变化，不改变粒子寿命。
- **Glow = 0** 时清晰颗粒仍存在。
- **Stop emission** 是绝对停止发射时间；-1 表示持续。停止后已有粒子自然消失。
- **Prewarm** 让第 0 帧已有粒子；负时间的来源固定读取第 0 帧。

## 3. 预设面板

### 内置预设

面板提供 6 个起点：元素闪耀、细尘拖尾、星芒拖尾、轻柔漂移、向外火花、背景浮尘。选择后可阅读说明并应用到选中的 Nebula Particle 效果。

这些是技术与视觉起点，不是已经完成的大型成品预设库。面板的内置值与原生 Preset 下拉共同服务于当前效果；切换来源后仍可复用相同外观。

### 保存“我的预设”

1. 在 AE 中选中需要保存的 Nebula Particle 效果。
2. 调整视觉与运动数值，定位到希望采样的时间。
3. 在面板中选择保存，输入名称。
4. 到“我的预设”列表查看并应用；需要时使用刷新重新读取文件。

保存内容为当前帧的 17 项数值：Density、Size、Lifetime、Particle shape、Particle blend、Color mode、Tint color、Initial speed、Direction、Spread、Damping、Fade in、Fade out、Twinkle strength、Twinkle frequency、Glow、Opacity。

不保存动画曲线。应用时保留目标效果的来源图层、颜色图层、外部遮罩、发射通道、随机种子、预热、停止发射时间、Show source 与原生 Preset 下拉值。

如果任何待修改参数已有关键帧或表达式，整次应用会拒绝，避免覆盖动画或只改到部分参数。相同名称自动另存为带序号的名称，原文件保留。

用户预设以 `.papreset` 数据文件保存在 `Folder.userData` 下的 `Nebula Particle/User Presets/`。旧 `Particle Atelier/User Presets/` 目录以只读方式合并进列表，新保存只写新目录。预设数据不是可执行脚本，当前不提供自动删除预设功能。

## 4. 测试工作流

先使用项目生成的几何序列验证，避免输入素材差异干扰判断：

```sh
python3 scripts/make-fixtures.py
python3 scripts/test-ae.py
```

脚本生成独立工程并调用实际 AE 渲染器；不安装插件，也不自动关闭正在运行的 GUI。集成脚本当前针对 AE 2023 标准 macOS 安装位置。执行前保存工作，其他版本先检查脚本配置。

也可在空工程运行 `scripts/create-test-project.jsx`，依次检查：

1. **Alpha trail - damping 0**：主体运动已经烘焙在 PNG 序列里，没有位置关键帧。
2. **Alpha trail - damping 2**：与前者比较，检查射出后减速。
3. **External luminance trail**：外部亮度通道决定出生区域，独立颜色图决定颜色。
4. **Stop emission test**：停止时间后不再出生，寿命结束后输出透明。
5. **After footage end**：素材结束后，已有粒子仍存活到各自寿命结束。

生成的工程、素材和输出都放在本地 `test-output/`，不随仓库分发。实际预览应使用自行生成的文件，不依赖开发者的绝对目录。

## 5. 更新资源与代码

修改 `resources/presets.ini` 后运行：

```sh
bash scripts/update-presets.sh
```

再使用 **Advanced → Development tools → Reload current preset**。它重读外部预设并重新应用当前内置预设的视觉参数；保留图层连接、发射通道、种子与停止时间。

该按钮不重载原生 C++，也不是 GPU 热更新。修改原生代码或参数结构后仍需构建、安装并启动新 AE 会话。

## 6. 已知限制

- CPU 参考实现；GPU、光流、三维、景深、Z 输出、克隆与正式烘焙尚未接入。
- 宿主路径支持 8/16 bpc；不声明 32 bpc/HDR。内部浮点高光会受最终宿主位深限制。
- 没有开启 AE 多帧渲染支持标志，没有正式历史帧或模拟磁盘缓存。
- 普通效果 checkout 不保证自动包含来源图层的前序效果、遮罩和变换；初测使用烘焙序列或预合成。
- 所有来源通过归一化图像坐标对齐。建议预合成为同尺寸、同帧率、同起点；外部图层 Transform 未自动解析。
- 发射分布使用最长边 192 的近似网格，颜色输入最多 384 像素分析尺寸。极细线条可能漏采，颜色不是逐像素高精度重建。
- 灰度作为空间权重分配总出生量；整张遮罩统一变暗不会按同一比例减少总出生量。
- 初速、阻尼、密度、寿命等模拟控制暂不提供时间关键帧。整体调参可能改变历史轨迹；停止发射使用专门的绝对时间参数。
- 输出范围为承载图层范围。建议使用合成尺寸的承载层，避免飞出小尺寸素材边界后裁切。
- 当前按 X 向预览比例缩放大小与速度；非方形像素和非等比预览未完成验收。
- 粒子内部混合与源图显示是两步；Add / Screen 不等于整个效果层对下方背景的混合模式。
- 预设保存当前数值，不保存曲线、图层连接、素材或完整合成。
