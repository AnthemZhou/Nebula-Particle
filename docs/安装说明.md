# Nebula Particle 0.5.0 安装说明

发布包：`Nebula-Particle-0.5.0-macos-arm64.zip`

平台：macOS arm64

当前验证宿主范围：After Effects 23.6

安装编译好的发布包不需要 Adobe SDK、Xcode 或自行编译。SDK 只在[从源码构建](SDK准备.md)时需要。

## 下载安装

1. 从 [v0.5.0 Release](https://github.com/AnthemZhou/Nebula-Particle/releases/tag/v0.5.0) 下载 `Nebula-Particle-0.5.0-macos-arm64.zip`，不要把 Source code ZIP 当作插件安装包。
2. 解压后保持目录完整；保存当前工程并退出 AE。
3. 运行根目录的 `install-macos.command`。它调用包内两个安装脚本，安装原生效果与预设面板。
4. 重新启动 AE，在“效果和预设”中搜索 **Nebula Particle**。
5. 从“窗口”菜单打开 **Nebula Particle Presets.jsx**，选择内置预设开始使用。

如果从终端执行，先进入解压目录：

```sh
bash ./install-macos.command
```

默认面板目标为 AE 偏好版本 `23.6`。选择其他版本时使用 `AE_VERSION`，例如 `AE_VERSION=23.6 bash ./install-macos.command`；改变目录目标不代表该 AE 版本已经完成兼容性验证。

当前原生包使用 ad-hoc 签名，尚未经过 Apple 公证。macOS 可能显示开发者验证或运行提示；这不等同于已经公证的商业安装包。安装器不修改 macOS 安全设置，也不会自动关闭 AE。

## 包内文件

```text
install-macos.command
build/
└── Nebula Particle.plugin/
scripts/
├── install-dev.sh
├── install-panel.sh
├── Nebula Particle Presets.jsx
└── NebulaParticlePresetLib.jsxinc
LICENSE
README.md
README_EN.md
CHANGELOG.md
CONTRIBUTING.md
INSTALL.txt
SOURCE.txt
docs/
```

插件和面板是两部分：原生效果负责渲染，ScriptUI 面板负责预设操作。面板的 JSX 与 `.jsxinc` 库必须保持同目录，不能只复制其中一个。

发布包包含中英介绍、安装说明、完整 GPLv3 许可证和源代码定位信息。对应源码在 [v0.5.0 标签](https://github.com/AnthemZhou/Nebula-Particle/tree/v0.5.0)，不包含 Adobe SDK。

## 安装位置

原生插件安装到用户级 MediaCore：

```text
~/Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore/Nebula Particle.plugin
```

预设面板安装到相应 AE 偏好版本的用户级 ScriptUI 目录：

```text
~/Library/Preferences/Adobe/After Effects/23.6/Scripts/ScriptUI Panels/
```

这些是用户目录，正常安装不需要系统级插件目录的管理员权限。原生更新需要新 AE 会话；清空图像缓存不能代替重新加载插件。

## 从旧名称升级

早期开发版本使用名称 **Particle Atelier**。0.5.0 将对外名称统一为 **Nebula Particle**，内部效果匹配名 `ParticleAtelier.Particles` 与已有参数磁盘 ID 保持不变，用于兼容已保存工程。不要为了让名称“看起来一致”手动修改这些内部标识。旧工程已经保存的效果实例名称可能仍显示旧名，不代表需要再安装一份旧插件。

安装器核验旧包标识后，会把旧名和同名的已安装插件备份移出扫描位置，再安装新包，避免两份效果同时注册。旧面板脚本也会备份移走；不会删除用户的旧预设数据。

数据兼容规则：

- 新的资源与用户预设写入 **Nebula Particle** 数据目录。
- 新的 `presets.ini` 不存在时，可读取旧目录资源；安装器只在新文件缺失时复制旧资源，不覆盖已有新资源。
- “我的预设”列表会只读合并旧 **Particle Atelier/User Presets/** 目录；新保存写入 **Nebula Particle/User Presets/**。
- 旧数据不需要用户手工删除。相同名称的用户预设继续采用另存序号规则。

## 找不到效果或面板

- 确认使用的是 macOS arm64 发布包，而非 Source code ZIP。
- 安装后重新启动 AE，再检查效果搜索和“窗口”菜单。
- 面板目录中的两个脚本文件必须齐全；面板偏好版本应与实际 AE 对应。
- 如需隔离面板菜单发现问题，可通过“文件 → 脚本 → 运行脚本文件”运行 `Nebula Particle Presets.jsx`，以浮动窗口验证。
- 向 [Issues](https://github.com/AnthemZhou/Nebula-Particle/issues) 反馈时附上插件与 AE 版本、系统架构和具体错误，不上传私人目录或素材。

功能范围、参数与已知限制见[使用说明](验证版使用说明.md)。
